How to report

Reports come from players, one form per game and setup.

Open the form

Fill in the report form for the game you tried.

One report per setup

Send one report per game and setup. If you tried the same game on two consoles, send two reports.

Pick a status

Perfect: no problems found. Playable: small problems, can be finished. Has problems: big problems, crashes or can't be finished. Won't start: never gets in-game.

Where to find things

The Game ID is on the game's page in RiftWii. Write the RiftWii version and cIOS as RiftWii shows them. For a crash, attach a problem report from Settings > Help > Send a problem report (how to send one).

Don't post personal info. CISO files aren't supported: convert to ISO or RVZ in Dolphin first. Without a GitHub account, a Discord route is coming.
